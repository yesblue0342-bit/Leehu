Hermes KH(이하 “앱”)는 계정 소유자가 자신의 Stella-NUC에서 사용하는 개인용 Google Workspace 비서입니다. 이 방침은 앱이 Google 사용자 데이터를 어떻게 접근·사용·저장·보호하는지 설명합니다.

1. 접근하는 데이터

사용자가 승인한 범위에서 Gmail 메시지와 메타데이터, Calendar 일정, Drive 파일과 Docs·Sheets·Slides 콘텐츠, Contacts 연락처, Tasks 할 일 및 OAuth 인증 토큰에 접근할 수 있습니다.

2. 이용 목적

데이터는 사용자가 명시적으로 요청한 이메일·일정·파일·문서·연락처·할 일 작업을 수행하고 결과를 사용자에게 제공하는 목적으로만 사용합니다. 광고, 판매, 신용평가, 사용자 프로파일링 또는 범용 AI 모델 학습에 사용하지 않습니다.

3. 저장과 보유

OAuth 토큰은 접근 보호된 Stella-NUC의 로컬 사용자 영역에 저장됩니다. Google 콘텐츠는 요청 처리 중 필요한 만큼만 조회하며, 사용자가 별도로 저장을 요청한 결과 외에는 독립적인 사용자 데이터베이스로 장기 보관하지 않습니다.

4. 공유 및 이전

Google 사용자 데이터를 판매·대여하지 않으며 제3자 광고업체와 공유하지 않습니다. 사용자의 명시적 지시를 수행하거나 법률상 요구되는 경우를 제외하고 제3자에게 이전하지 않습니다.

5. 보호 조치

로컬 운영체제의 사용자 접근 제어, 암호화된 HTTPS 통신, 최소 권한 원칙 및 OAuth 권한 취소 기능을 사용합니다. 인증 토큰은 공개 페이지나 소스 코드에 노출하지 않습니다.

6. 사용자 통제와 삭제

사용자는 Google 계정의 보안 설정에서 언제든 앱 권한을 취소할 수 있습니다. 로컬 토큰 또는 앱이 저장한 결과의 삭제는 아래 연락처로 요청할 수 있으며, 확인 후 지체 없이 처리합니다.

7. Google API 제한적 사용

Hermes KH의 Google API 사용자 데이터 이용은 Google API Services User Data Policy와 그 Limited Use 요건을 준수합니다.
