## 권장 조치

### 1. 네이버에 제출하는 피드를 본문 전체·용량 한도에 맞춘다

**Do this**

- 서치어드바이저 RSS 제출: `literature/feed.xml`(최신 100편, 본문 전체, 약 0.47MB)과 `seo-updates/rss.xml`(공식 소식 34편, 본문 전체).
- 기존에 `literature/rss.xml`을 제출해 두었다면 삭제합니다. 이 파일은 문학노트 목록의 검색 기능이 읽는 전체 색인이라 사이트에는 그대로 둡니다.

**Why**

- 네이버 가이드는 RSS 항목에 본문 전체를 담고 10MB 미만일 것을 요구합니다. 기존 피드는 요약만 담고 용량 여유가 약 158편뿐입니다.
- 사이트맵(5,732 URL, 0.83MB)이 전체 URL을 담으므로 RSS는 최신 글만 담으면 됩니다.

| 피드 | 항목 | 용량 | 본문 |

| literature/rss.xml (사이트 내부 검색용) | 5,692 | 9,728,730 bytes | 요약(해설 문단만) |

### 2. 인물정보가 보내는 프로필 페이지에서 동명이인 구분 사실을 바로 보이게 한다

**Do this**

- `/author/` 첫 문단과 기본 정보에 출생(1982년 4월 30일, 경기도 성남), 한자 표기, 2011년 소설 《연》 데뷔, 아버지 시인 김경(金敬), 네이버 인물정보 ID 215161을 표시하고, "같은 이름의 다른 인물과 어떻게 구분하나요?" 질문을 질문 목록과 구조화 데이터에 함께 추가했습니다.
- 홈 첫 화면에 같은 사실 한 줄(1982년 성남 출생 · 2011년 소설 《연》 데뷔 · 아버지 시인 김경)을 추가했습니다.

**Why**

- 네이버 인물정보의 공식홈페이지 링크가 `/author/`로 연결되는데, 그 페이지 본문에는 출생·성남 같은 구분 사실이 없었습니다(설명 메타와 구조화 데이터에만 있었음).
- 모두 사이트와 교보문고·인물정보에 이미 공개된 사실만 사용했고, 다른 인물의 이름이나 정보는 쓰지 않았습니다.

### 3. 사이트 연관채널 마크업과 채널 목록을 네이버 인물정보와 맞춘다

**Do this**

- 루트 페이지에 네이버 가이드 형식 그대로의 Person(name·url·sameAs) 블록을 추가했고, sameAs는 네이버가 인식하는 채널(블로그·네이버TV·유튜브·인스타그램·X·페이스북)만 담았습니다. 같은 `@id`를 써서 기존 Person과 병합됩니다.
- 인물정보에 등록된 페이스북 주소를 홈·프로필·작품·공식 출처의 sameAs와 보이는 채널 목록에 추가했습니다.
- 우측 하단 모노그램 버튼을 스크립트 대신 네이버 인물정보로 가는 일반 링크로 바꿨습니다(검색로봇이 따라갈 수 있는 `<a href>`).

**Why**

- 네이버는 루트 페이지의 Person/Organization sameAs로 사이트와 채널의 연관성을 분석합니다. 기존 sameAs는 @graph 안에 검색 URL·서점·위키가 섞여 있었습니다.
