### 원인과 수정 범위

`scripts/build_literature.py:additional_sitemap_urls()`는 색인 가능한 소식 폴더의 게시일 중 최댓값을 소식 목록의 `lastmod`로 사용합니다. 현재 날짜나 파일 수정 시각을 사용하지 않습니다. 기존 게시 커밋들은 새 소식 URL을 사이트맵에 추가했지만 목록 URL `/seo-updates/`의 날짜는 `2026-10-01`에 머물러 있었습니다. PR 생성 당시의 올바른 값은 `2026-10-31`, 이번 최신 main을 포함한 값은 `2026-11-02`입니다.

생성 정책은 유지하고 기존 생성기로 `sitemap.xml`을 재생성했습니다. URL 집합은 그대로이며 날짜가 달라진 항목은 소식 목록 하나뿐입니다. 실행일로 강제 갱신하거나 불일치를 무시하지 않았습니다.

`test_z_generator_is_idempotent`는 같은 대상 파일 전체를 계속 바이트 단위로 비교합니다. 실패 시 수천 개 HTML 전문을 포함한 사전 diff를 만들던 부분만 변경 파일 경로 목록으로 바꿨습니다. 재생성 프로세스 성공 여부와 상세 페이지 수 검사도 유지했습니다. 날짜 정책·noindex 제외·안정적인 기본 날짜·저장된 사이트맵의 실제 날짜를 확인하는 테스트 3개를 추가했습니다.

Windows 전체 실행에서 별도로 드러난 SEO 감사 경로 구분자 문제도 수정했습니다. 상대 경로를 `Path.as_posix()`로 변환해 Windows와 Linux의 결과 표기와 경로 분류가 같도록 했으며 기존 기대값은 변경하지 않았습니다.
