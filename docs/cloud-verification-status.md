# 클라우드 개발 도구 검증 결과

## 확인한 범위

- 기본 점검 14개가 통과했습니다. 공개 HTTP 경로, 작가 정보, 색인 정책과 IndexNow 회귀를 검사했습니다.
- Chromium에서 데스크톱·모바일 각 5개 경로의 HTTP, 제목·본문, canonical과 내부 이동 검증을 통과했습니다.
- `scripts/literature_batch.py verify`는 원본·상세 7,191개, 색인 5,692개, RSS 5,692개, feed 100개를 확인했습니다. 이 숫자는 이번 검증 시점의 값입니다.
- 새 Python 진입점 문법, 문서 링크와 공백 검사를 통과했습니다.

## 전체 검사에서 확인한 기존 문제

최초 전체 실행에서는 `/data` 쓰기 권한 오류가 발생했습니다. 점검 진입점이 테스트 경로를 임시 디렉터리로 지정하도록 수정했고 해당 HTTP 회귀 검사 5개를 포함한 기본 검사를 다시 통과했습니다.

전체 검사에 포함된 기존 `test_z_generator_is_idempotent`는 사이트맵 재생성 전후의 차이로 동일성 조건을 만족하지 못했습니다. 기존 `/seo-updates/`의 lastmod는 `2026-10-01`, 재생성 결과는 `2026-10-31`이었습니다. 다른 URL의 변경은 확인되지 않았습니다. 실패한 대형 사전의 상세 diff를 만드는 과정에서 프로세스 상주 메모리가 14GiB를 넘어 해당 실행을 중단했습니다. 따라서 전체 검사 통과로 보고하지 않습니다.

이번 작업은 개발 도구·지침 보완이며 사이트맵 정책·앱·기존 테스트를 수정하지 않았습니다. 검사가 만든 사이트맵 변경은 되돌렸고 운영 배포와 검색엔진 제출은 수행하지 않았습니다. 전체 통과에는 이 기존 생성 산출물 불일치와 실패 진단의 메모리 사용 문제에 대한 별도 수정·재검증이 필요합니다.
