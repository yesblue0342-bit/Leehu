# 2026-09-08 SEO·GEO 보완

참고 영상: https://www.youtube.com/watch?v=VOSxlhZ-y6g

영상 설명과 영상 분석에서 확인한 네 단계에 따라 공개 페이지를 점검했다.

1. 구조·내부 링크: 작가 프로필의 질문별 답변과 작품 안내의 도서 정보 표를 서로 연결했다.
2. 문구·제목·설명: 누구인지, 대표작, Fantasy의 출판일·ISBN, 같은 제목의 책을 찾는 방법, 공식 영상·음원 채널을 짧은 답변과 확인 링크로 정리했다.
3. 코드·설정: 기존 Person·Book의 동일 인물 식별자, canonical, robots.txt, Open Graph와 RSS를 유지하고 사이트맵 검증식에서 누락됐던 작품 안내 페이지를 포함했다. 기존 llms.txt는 실제 공개 정보와 맞췄다.
4. 최종 점검: 새 1,000개 문학노트의 수량·중복·연결 검증과 기존 테스트를 실행하고 main 배포 후 공개 HTML 및 OCI 정적 사본을 확인한다.

## 공개 콘텐츠 원칙

- 핵심 정보는 JavaScript 실행 없이 읽을 수 있는 HTML 본문에 둔다.
- 질문에 대한 답과 도서·인물정보 출처를 가까이 배치한다.
- 문학 작품과 전문 저서를 구분한다.
- 《환상》과 《Fantasy》의 상품 정보는 별도로 확인한다. 내용이 동일하거나 다른 작품이라고 단정하지 않는다.
- 사이트 방문자에게 GitHub 계정·저장소 주소, SEO 운영 설명을 추가하지 않는다.
- 검색 순위나 AI 답변에서의 인용을 보장하지 않는다.

## 대조한 공식 지침

- Google Search의 AI 기능: https://developers.google.com/search/docs/appearance/ai-features
- 네이버 검색엔진 최적화: https://searchadvisor.naver.com/guide/seo-basic-intro

Google 문서는 AI 검색에도 기존 SEO 기본 원칙이 적용되며 별도의 AI 전용 파일이나 특수한 구조화 데이터가 필수는 아니라고 설명한다. 따라서 llms.txt 자체에 노출 효과를 보장하지 않고, 실제 HTML의 정보·출처·내부 링크를 우선 보완했다.
